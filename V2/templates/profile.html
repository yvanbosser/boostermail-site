💬 Problème de connexion ? Voir les solutions
Je n'arrive pas à me connecter à mon compte Microsoft
1. Vérifiez que vous utilisez bien le compte Microsoft associé à Outlook (et non un compte personnel différent).
2. Cliquez sur « Se reconnecter » en haut de cette section.
3. Une fenêtre Microsoft s'ouvre — saisissez votre mot de passe et acceptez les autorisations BoosterMail.
4. Si la fenêtre se ferme avant que vous ayez cliqué sur Accepter, recommencez.
La fenêtre de connexion Microsoft s'est fermée toute seule
C'est souvent dû au bloqueur de popups de votre navigateur. Autorisez les popups depuis api.boostermail.ai, puis cliquez sur « Se reconnecter ».
Microsoft me dit que mon compte n'a pas Outlook
BoosterMail nécessite un compte avec Outlook activé : Microsoft 365 (perso ou pro), Outlook.com, ou un compte Exchange/Office 365 d'entreprise. Si votre compte n'a pas Outlook, contactez votre admin IT ou créez un compte Microsoft 365.
Quelle version d'Outlook utiliser avec BoosterMail ?
BoosterMail fonctionne avec les 3 versions modernes d'Outlook :
• New Outlook (Monarch — celui par défaut sur Windows 11)
• Outlook Classic (l'ancien client desktop)
• Outlook Web (outlook.office.com dans votre navigateur)

Vous pouvez utiliser celle qui vous convient — BoosterMail s'adapte automatiquement.
Toujours bloqué ? Écrivez-nous : support@boostermail.ai
