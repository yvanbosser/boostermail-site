📌 Questions fréquentes
Je ne trouve pas BoosterMail dans Outlook ?
🔍 BoosterMail s'installe à 2 endroits dans Outlook :

1. Dans le ruban = la grande barre horizontale en haut de la fenêtre Outlook (avec Nouveau message, Répondre, Transférer…). Toujours visible.

2. Dans la barre d'actions d'un mail = juste au-dessus du contenu quand vous ouvrez un mail (avec Répondre, Répondre à tous, Transférer, souvent sous forme de flèches).

Lequel ne fonctionne pas chez vous ?
Le 🚀 n'apparaît pas dans le ruban d'Outlook ?
📍 Le ruban = la grande barre horizontale en haut de la fenêtre Outlook (où se trouvent Nouveau message, Répondre, Transférer…). Toujours visible quand Outlook est ouvert.

Si le bouton 🚀 n'apparaît pas dans le ruban :
  1. Fermez complètement Outlook (clic droit dans la barre des tâches → Quitter, pas juste la croix).
  2. Rouvrez Outlook. Le bouton 🚀 doit maintenant apparaître.
  3. Si toujours invisible : Profil → 🚀 Bouton Outlook → Réinstaller le bouton, puis refermez/rouvrez Outlook.
  4. Si ça persiste : support@boostermail.ai
Le 🚀 n'apparaît pas dans la barre d'actions / comment l'épingler ?
📍 La barre d'actions du mail = la ligne de boutons Répondre, Répondre à tous, Transférer (souvent sous forme de flèches) qui apparaît juste au-dessus du contenu d'un mail quand vous le cliquez.

(Cette barre existe sur New Outlook et Outlook Web. Sur Outlook Classic, les add-ins se trouvent dans le ruban — voir la question précédente.)

Par défaut, Outlook cache les boutons d'add-ins (dont 🚀) derrière une petite icône carrée à 4 sous-carrés (⊞) à droite de la barre d'actions. Pour épingler 🚀 BoosterMail :
  1. Ouvrez n'importe quel mail
  2. Repérez l'icône carrée à 4 sous-carrés (⊞) à droite
  3. Cliquez dessus → vous voyez la liste des add-ins
  4. Clic droit sur 🚀 BoosterMail → Épingler
  5. Le bouton est désormais toujours visible
Comment recalibrer mon style d'écriture ?
BoosterMail apprend votre style en analysant vos mails envoyés et reçus. Pour relancer l'analyse :

Profil → Style rédactionnel → Recalibrer BoosterMail

L'analyse prend quelques minutes. Plus vous envoyez de mails, plus BoosterMail s'affine.
Comment changer mon dossier de classement des pièces jointes ?
Pour modifier le dossier où BoosterMail propose de classer vos pièces jointes :

Profil → 📁 Pièces jointes → bouton 📁 Parcourir → sélectionnez votre nouveau dossier.

BoosterMail réindexe automatiquement votre arborescence (~quelques secondes).
Confidentialité : que voit BoosterMail de mes données ?
Vos mails sont analysés par l'IA Claude (Anthropic, USA) pour générer vos réponses. Nos engagements :
  • Chiffrement en transit (HTTPS) et au repos (serveurs OVH France)
  • Pas d'entraînement IA sur vos mails (DPA Anthropic signé)
  • Logs minimaux : nous n'enregistrons pas le contenu de vos mails
  • Suppression à la demande : Profil → exporter ou supprimer toutes vos données
Politique complète : boostermail.ai/privacy
Pourquoi BoosterMail tourne-t-il en tâche de fond ?
Pour 3 raisons :
  1. Rapidité : préparer vos réponses à l'avance → prêtes en 2-3 sec au clic
  2. Synchronisation Outlook : détecter les nouveaux mails et organiser vos PJ
  3. Apprentissage continu : analyser votre style au fil de vos envois
Consommation très faible : ~30 Mo de RAM, aucun impact CPU notable.
Comment désinstaller BoosterMail ?
  1. Fermez Outlook
  2. Panneau de configuration → Programmes → BoosterMail → Désinstaller
  3. Le bouton 🚀 disparaît d'Outlook au prochain démarrage
Vos données restent 30 jours côté serveur puis sont supprimées. Pour tout effacer immédiatement : Profil → Confidentialité → Supprimer mes données.
