Installer BoosterMail pour Outlook

Assistant email intelligent qui rédige vos réponses dans votre style, adaptées à chaque correspondant. L'installation prend moins de 2 minutes.

Lien à copier : https://api.boostermail.ai/plugin/manifest.xml
Ouvrir le sideload Outlook → S'ouvre dans Outlook (Web ou Desktop). Suivez les étapes ci-dessous.

Comment installer en 5 étapes

1

Copier le lien du manifest

Cliquez sur Copier en haut de cette page. Le lien https://api.boostermail.ai/plugin/manifest.xml est maintenant dans votre presse-papier.

2

Ouvrir l'installeur de compléments Outlook

Cliquez sur le bouton « Ouvrir le sideload Outlook » ci-dessus, ou rendez-vous sur aka.ms/olksideload. La fenêtre Mes compléments s'ouvre.

3

Choisir « Ajouter un complément personnalisé »

En bas de la fenêtre, cliquez sur « Ajouter un complément personnalisé » puis « Ajouter à partir d'une URL ».

4

Coller le lien du manifest

Collez l'URL copiée à l'étape 1 dans le champ, validez avec OK, puis acceptez les permissions demandées.

5

C'est prêt !

Le bouton BoosterMail apparaît dans votre ruban Outlook. Ouvrez un mail, cliquez dessus et générez votre première réponse intelligente.

Questions fréquentes

Le lien aka.ms/olksideload ne fait rien chez moi

Ouvrez Outlook → menu Accueil → Obtenir des compléments → onglet Mes compléments → Ajouter un complément personnalisé → Ajouter à partir d'une URL.

BoosterMail est-il gratuit ?

Pendant la phase beta, oui. Les tarifs payants seront communiqués avant le passage en version commerciale ; aucun prélèvement automatique sans accord explicite.

Qu'est-ce qui est envoyé à BoosterMail ?

Uniquement le contenu strictement nécessaire pour générer la réponse : objet, corps du mail courant, et historique pertinent. Aucune donnée n'est revendue. Les clés API et tokens sont chiffrés côté serveur.

Comment désinstaller ?

Dans Outlook : Obtenir des compléments → Mes compléments → BoosterMail → Supprimer.

Je rencontre un problème, comment être aidé ?

Écrivez à yvan.bosser@gmail.com en décrivant la version d'Outlook utilisée et le message d'erreur exact si possible.
