Configurez BoosterMail en 2 minutes

3 étapes guidées pour profiter pleinement de votre assistant IA dans Outlook.

ÉTAPE 1 · 30 SECONDES

Autoriser les popups depuis BoosterMail

BoosterMail s'ouvre dans une popup pour générer vos réponses. Sur certains navigateurs (Edge, Chrome), il faut l'autoriser explicitement la première fois.

Pourquoi c'est important : sans cette autorisation, votre clic sur le bouton BoosterMail ne fait rien (la popup est silencieusement bloquée par le navigateur).

Cliquez sur le bouton ci-dessous pour tester. Si une popup apparaît, c'est OK ! Sinon, votre navigateur la bloque.

Comment autoriser les popups si bloquées ?
  1. Microsoft Edge / Chrome : cliquez sur l'icône en bout de barre d'adresse (souvent un cadenas ou un mini-écran avec ❌). Choisissez « Toujours autoriser les pop-ups » depuis ce site.
  2. Firefox : cliquez sur le bandeau jaune en haut de la page → « Autoriser les pop-ups ».
  3. Safari : Préférences → Sites web → Pop-up → Autoriser pour ce domaine.
  4. Revenez ici puis re-cliquez sur « Tester l'ouverture popup ».
ÉTAPE 2 · 30 SECONDES

Activer le placement intelligent (multi-écrans)

Si vous avez plusieurs écrans, BoosterMail peut s'ouvrir automatiquement sur le bon écran (à côté d'Outlook). Cette permission s'appelle window-management côté navigateur.

Pourquoi c'est utile : sans cette permission, la popup BoosterMail s'ouvre toujours sur l'écran principal, même si Outlook est sur un autre écran. Avec, elle suit Outlook automatiquement.

Cliquez sur le bouton ci-dessous puis répondez « Autoriser » dans la popup du navigateur.

Vous avez un seul écran ? Cette étape est optionnelle

Si vous travaillez sur un seul écran, BoosterMail s'ouvrira correctement sans cette permission. Vous pouvez passer cette étape en toute sécurité.

ÉTAPE 3 · 1 MINUTE

Épingler le bouton BoosterMail dans Outlook

Microsoft Outlook range les add-ins comme BoosterMail dans un menu secondaire « Plus d'apps » (le petit carré avec 4 points dans la barre d'actions). Pour le voir tout le temps, il faut l'épingler.

Pourquoi c'est important : si BoosterMail n'est pas épinglé, vous devez cliquer 2 fois pour l'ouvrir (Plus d'apps → BoosterMail). Une fois épinglé, c'est 1 seul clic.

Comment faire :

  1. Dans Outlook (web ou New Outlook desktop), ouvrez n'importe quel mail.
  2. En haut à droite, cliquez sur l'icône « Plus d'apps » ou « Apps » (le carré avec 4 points).
  3. Trouvez BoosterMail dans la liste qui s'ouvre.
  4. Faites clic-droit sur BoosterMail.
  5. Choisissez « Épingler » (ou « Pin »).
