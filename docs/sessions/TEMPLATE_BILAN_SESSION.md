# Template — Bilan de fin de session

> **Usage** : copier ce template au début d'un nouveau bilan, renommer en `OUTLOOK_BILAN_SESSION_<YYYYMMDD>_<scope>.md` ou `SAAS_BILAN_SESSION_<YYYYMMDD>_<scope>.md`, remplir.

---

## 🚨 RÈGLE GIT ABSOLUE — rappel obligatoire dans CHAQUE bilan

| Contributeur | Branche de push obligatoire |
|---|---|
| **Yvan** | `feat/yvan/frontend` |
| **Michael** | `feat/michael/multi-user` |

**JAMAIS de push direct sur `dev` ou `master`.** Détails : [`docs/CONVENTIONS_GIT_BRANCHES.md`](../CONVENTIONS_GIT_BRANCHES.md).

À recopier en haut de chaque bilan pour qu'une session future qui ouvre directement le bilan voie la règle sans avoir à remonter.

---

## Métadonnées

- **Date** : YYYY-MM-DD
- **Contributeur** : Yvan / Michael
- **Branche de travail** : `feat/yvan/frontend` ou `feat/michael/multi-user`
- **Scope session** : 1 phrase
- **Top commit local** : `<sha>`
- **Top commit remote (`product/<branche>`)** : `<sha>`
- **PR ouverte vers `dev` ?** : oui (lien) / non / déjà mergée
