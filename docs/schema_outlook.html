💡 Le point clé à retenir

EasyMail parle à Outlook Desktop (le logiciel sur le PC).
Peu importe où sont stockés les mails (Microsoft, OVH, ou autre) — si Outlook Desktop est installé, EasyMail fonctionne.

En résumé : la question à poser à un bêta-testeur

"Tu as Outlook installé sur ton PC ?" → Si oui → EasyMail fonctionne ✅
"Tu utilises Outlook uniquement dans le navigateur ?" → Si oui → pas compatible pour l'instant ❌
